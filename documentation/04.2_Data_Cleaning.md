# 11. Data Cleaning & Preprocessing Documentation

## Objective

The objective of this step was to improve the quality, consistency, and reliability of the datasets before performing further analysis.

The cleaning process was performed on working copies of the original datasets so that the source data remained unchanged.

---

Working copies were created for all datasets:

- Customers
- Orders
- Order Items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Category Translation

This ensured that all cleaning operations were performed safely without modifying the original datasets.

---

## 2. Missing Value Treatment

Missing values were reviewed dataset by dataset and treated according to their business meaning.

### Products

Missing product category values were replaced with:

`unknown`

This was preferred over guessing the category because the correct category could not be reliably determined from the available data.

Missing numeric product attributes were replaced using the median value of the respective column.

The median was used because it is less sensitive to extreme values than the mean.

### Orders

The Orders dataset contained 4,908 missing values.

These missing values were not blindly removed or artificially filled because some date/event fields can legitimately remain unavailable when an event did not occur or was not recorded.

Therefore, these values were retained for business-context analysis.

### Reviews

Missing textual review information was replaced with:

`not_available`

Review scores were not artificially generated because creating a review score without source information could introduce incorrect information into the analysis.

### Other Datasets

Customers, Order Items, Payments, Sellers, Geolocation, and Category Translation did not contain missing values requiring treatment.

---

---

## 4. Text Standardization

Text-based columns were standardized by removing unnecessary leading and trailing spaces.

This helps maintain consistency in fields such as:

- City
- State
- Category
- Customer information
- Seller information
- Product information
- Review text

The standardization improves the reliability of filtering, grouping, joining, and aggregation operations.

---

## 5. Product Weight Validation

The `product_weight_g` column was validated because product weight should represent a positive physical measurement.

Zero or non-positive product weights were considered invalid.

A median of valid positive product weights was calculated and used to replace invalid values.

This treatment avoids retaining physically invalid measurements while minimizing the effect of extreme values.

# 13. Data Cleaning Strategy

Data cleaning decisions were based on both data-quality checks and business context.

The following treatment principles were applied:

- **Keep** reliable records without modification.
- **Replace** missing values where a reasonable neutral or statistical treatment was appropriate.
- **Transform** data to improve consistency and usability.
- **Remove** exact duplicate records that could distort analysis.
- **Retain** business-meaningful missing values instead of making unsupported assumptions.
- **Flag for investigation** any issue that could not be safely resolved through automated cleaning.

No records were removed without identifying the reason for removal.
