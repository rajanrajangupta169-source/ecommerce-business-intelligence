# 🛒 E-Commerce Business Intelligence

> End-to-End E-Commerce Data Analytics Project using MySQL, Python, and Power BI

---

## 📌 Project Overview

This project focuses on analyzing an e-commerce business using the Olist Brazilian E-Commerce Dataset. The main objective is to transform raw e-commerce data into meaningful business insights through data cleaning, database management, SQL analysis, exploratory data analysis, and interactive Power BI dashboards.

The project follows a complete end-to-end data analytics workflow, starting from raw datasets and progressing through MySQL, Python, and Power BI to generate actionable business insights and recommendations.

---

## 🎯 Project Objectives

- Analyze overall e-commerce sales performance.
- Identify revenue and order trends.
- Analyze customer and seller performance.
- Identify top-performing products and categories.
- Analyze revenue by state and payment method.
- Understand order status distribution.
- Analyze customer review scores.
- Identify important business trends and patterns.
- Build an interactive Power BI business dashboard.
- Generate data-driven business recommendations.

### 1. Raw Olist Dataset

The project starts with the original Olist Brazilian E-Commerce Dataset containing information about customers, orders, products, sellers, payments, reviews, and geolocation.

### 2. MySQL – Data Cleaning & Transformation

The raw datasets were imported into MySQL and organized into relational tables.

The MySQL stage includes:

- Database creation
- Table creation
- Data import
- Data cleaning
- Data transformation
- Data quality validation
- SQL-based business analysis
- KPI validation

### 3. Python – EDA & Data Analysis

Python was used to explore and analyze the cleaned data.

The analysis includes:

- Exploratory Data Analysis (EDA)
- Data exploration
- Data analysis
- Statistical analysis
- Trend identification
- Business pattern analysis
- Data visualization

### 4. Power BI – Interactive Business Dashboard

The analyzed data was used to develop an interactive Power BI dashboard for business reporting and decision-making.

The dashboard covers:

- Revenue performance
- Order performance
- Customer analysis
- Product analysis
- Category analysis
- Seller analysis
- State-wise revenue
- Payment methods
- Order status
- Customer reviews

### 5. Business Insights

The analytical findings were evaluated to identify important trends, customer behavior, sales patterns, product performance, seller performance, and operational insights.

### 6. Business Recommendations

Data-driven recommendations were developed based on validated analytical findings to support better business decision-making and improve business performance.

## 🗂️ Dataset

The project uses the Olist Brazilian E-Commerce Dataset.

The dataset contains the following CSV files:

| Dataset | Description |
|---|---|
| `olist_customers_dataset.csv` | Customer information and location |
| `olist_geolocation_dataset.csv` | Brazilian ZIP-code geolocation data |
| `olist_order_items_dataset.csv` | Products purchased in each order |
| `olist_order_payments_dataset.csv` | Payment information |
| `olist_order_reviews_dataset.csv` | Customer reviews and ratings |
| `olist_orders_dataset.csv` | Order information and order status |
| `olist_products_dataset.csv` | Product details |
| `olist_sellers_dataset.csv` | Seller information |
| `product_category_name_translation.csv` | Product category translation |
